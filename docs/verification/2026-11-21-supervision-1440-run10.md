## 3. Hallazgos nuevos

### SEC-GATE-006 — P1 — Las excepciones npm no quedan limitadas al advisory declarado

- **Evidencia:** `scripts/security-audit.mjs:92-93`; `scripts/security-audit-allowlist.json:3-9`.
- **Reproducción estática:** la allowlist declara `zod`, severidad `high` y advisory `GHSA-mrhx-c7xc-m3w5`. Sin embargo, `isExcepted(exceptions, pkg, severity)` compara únicamente paquete y severidad; no compara el advisory. El mismo helper se usa en el conteo npm.
- **Impacto:** cualquier advisory high futuro de `zod` puede quedar exceptuado automáticamente por una excepción que sólo justificaba un GHSA concreto. Esto puede producir un falso PASS del gate.
- **Recomendación:** exigir `advisory` como campo obligatorio y hacer que la excepción npm coincida por paquete + severidad + advisory; probar un segundo GHSA del mismo paquete y severidad para confirmar que bloquea.
- **Validación:** confirmado por lectura de código y allowlist; no se ejecutó npm audit.

### AUD-147 — P2 — El envelope de ducking entrega ~4,17 muestras/s, no ~20

- **Evidencia:** `apps/desktop/src-tauri/src/commands/domains/audio/audio_mix.rs:95-113`, especialmente línea 110.
- **Reproducción:** `hop_s = 0.01` genera una envolvente de 100 Hz. El stride actual es `48000 * 0.01 / 20 = 24`; `step_by(24)` reduce la respuesta a aproximadamente 4,17 puntos/s.
- **Impacto:** la IA recibe una envolvente mucho más escasa que la documentada; puede perder transitorios o detalles de actividad al inspeccionar la forma de nivel. Los keyframes de ducking se calculan por otra ruta y no se declaran afectados sin prueba.
- **Recomendación:** calcular el stride desde la frecuencia de la envolvente (`round(1 / (hop_s * 20))`, aproximadamente 5) y añadir un test que compruebe cantidad/espaciado de muestras para una duración conocida.
- **Validación:** cálculo estático; no se ejecutó el motor DSP.

### AUD-148 — P2 — Escritura WAV síncrona dentro de handlers async de audio

- **Evidencia:** `audio_mix.rs:212`, `audio_remix.rs:157`; handlers `audio_channels_convert` y `audio_remix_render`.
- **Reproducción estática:** la decodificación/procesamiento usa `spawn_blocking`, pero la codificación final y `std::fs::write(&dest, wav)` se ejecutan después de volver al handler async. Remix permite hasta 600 s; una salida estéreo float32 puede rondar 230 MB. La conversión de canales admite hasta 300 s.
- **Impacto:** escrituras grandes bloquean un worker del runtime async; si la escritura falla, el destino directo puede quedar parcial. No se midió latencia ni se probó un fallo de disco.
- **Recomendación:** mover encode + write a `spawn_blocking`, escribir a un temporal único y publicar mediante rename atómico después de validar tamaño/resultado.
- **Validación:** confirmado estáticamente; no se ejecutó render ni escritura de medios.

### AUD-149 — P2 — La grabación de voz no invalida el permiso pendiente al cambiar de proyecto

- **Evidencia:** `apps/desktop/src/features/editor/VoiceoverRecorder.tsx:229-252`; `apps/desktop/src-tauri/src/commands/domains/media/media/import.rs:206-251).
- **Reproducción estática:** después de `getUserMedia()`, el frontend valida el token de montaje/solicitud, pero no vuelve a comparar el ID del proyecto capturado antes del await. Si el usuario cambia de proyecto mientras el diálogo de permiso está abierto y el componente permanece montado, la grabación puede arrancar en el nuevo contexto; el guard posterior evita importar el audio al proyecto equivocado, pero no evita capturar hasta que se detenga.
- **Riesgo adicional de integridad:** el backend captura `session_root` antes de `spawn_blocking`. Si la sesión cambia mientras la importación está en curso, el archivo puede quedar copiado en la raíz anterior y el frontend rechaza montarlo después del await; puede quedar un medio huérfano.
- **Impacto:** captura inesperada tras un cambio de contexto y residuos de audio sin referencia en el documento del proyecto.
- **Recomendación:** invalidar/cancelar la solicitud al cambiar el ID del proyecto; volver a comprobarlo inmediatamente después de `getUserMedia`; asociar la importación a una generación/ID de sesión y revertir el archivo si la sesión deja de coincidir. Añadir tests con permiso e importación diferidos.
- **Validación:** confirmado por flujo estático; no se usó micrófono ni se cambió un proyecto durante una importación real.
