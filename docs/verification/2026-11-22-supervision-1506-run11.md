## Hallazgos nuevos

### AUD-150 — GuardProxy reenvía request-target absoluto al servidor de origen

- Severidad: P2 — compatibilidad de descargas HTTP.
- Evidencia: `apps/desktop/src-tauri/src/commands/domains/downloader/downloader/guard_proxy.rs:191-210, 261-280, 361`.
- `open_plain_http` valida la URL absoluta y conecta al origen, pero `force_connection_close` solo reescribe el header Connection; conserva la request-line `GET http://host/path ...`. El test de la línea 361 exige que siga en formato absoluto.
- Un proxy HTTP debe convertir la request-target absoluta a origin-form antes de reenviarla al servidor de origen. Algunos servidores rechazan o interpretan incorrectamente la forma absoluta, por lo que descargas/manifest HTTP pueden fallar. HTTPS CONNECT no usa este camino.
- Recomendación: reenviar `/path?query` (o `*` cuando corresponda), conservar Host, filtrar headers exclusivos del proxy y cambiar el test para exigir origin-form.
- Validación: confirmado estáticamente; no se hizo una descarga HTTP real.

### AUD-151 — cleanup del efecto anula el coalescing RAF del source monitor

- Severidad: P2 — seeks excesivos y posible stutter de preview.
- Evidencia: `apps/desktop/src/features/editor/MediaSpyOverlay.tsx:66-69`; `apps/desktop/src/features/editor/timeline-raf.ts:69-74`.
- El efecto depende de `spy.timeSeconds`, que cambia en cada pointer-move. Su cleanup ejecuta `flush()` antes de cada re-ejecución; `flush()` cancela el RAF y llama a `run()` inmediatamente. Por tanto, el coalescer aplica prácticamente cada movimiento en vez de agruparlo por frame.
- Recomendación: no hacer flush en el cleanup dependiente de cada muestra; reservar flush/cancel para cambio de asset y desmontaje, y añadir test que compruebe un solo seek por frame.
- Validación: confirmado por flujo React/coalescer; no se ejecutó test de UI.

### AUD-152 — rango In/Out invertido permite insertar un clip de un frame

- Severidad: P2 — edición incorrecta en timeline.
- Evidencia: `apps/desktop/src/features/editor/MediaSpyOverlay.tsx:126, 139-153, 245`.
- `hasMarks` solo comprueba que exista alguna marca y el botón se habilita con `!hasMarks`. Si Out es anterior a In, `Math.max(inFrame + 1, outFrame)` fuerza un rango de un frame; la UI puede mostrar un rango invertido y aun así insertarlo.
- Recomendación: rechazar o normalizar Out <= In, mostrar estado inválido y deshabilitar Insertar hasta corregirlo; añadir test de Out anterior a In.
- Validación: confirmado estáticamente; el test nuevo de MediaSpyOverlay no se ejecutó y no cubre ese caso.
