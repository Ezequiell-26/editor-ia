## Qué falta para "checkout limpio" literal

Procedimiento propuesto (NO ejecutado — requiere crear worktree/clone aparte y no tocar el árbol actual):

```bash
# Opción A: worktree limpio del HEAD actual
git worktree add ..\editor-ia-clean HEAD
cd ..\editor-ia-clean
npm ci                      # instala deps frescas según package-lock
node scripts/setup-ffmpeg-dev.mjs --quiet --runtime   # FFmpeg dev
npm run verify
node scripts/rust-env.mjs -- cargo test --lib -p editor-ia-desktop
# + los pasos de verify.yml no cubiertos por verify: cargo fmt --check,
#   render_live tests, Playwright e2e, audit:licenses

# Opción B: clone limpio + branch con el WIP commiteado (más fiel al estado actual)
git clone . ..\editor-ia-clean && cd ..\editor-ia-clean
# aplicar los 735 cambios (stash bundle / diff) o commitear en rama de QA
```

Nota: un checkout limpio de HEAD **no** incluirá los 735 cambios sin commitear — para reproducir este estado habría que materializarlos (commit en rama temporal o `git diff > patch` + `git apply`).
