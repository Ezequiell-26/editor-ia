# Stack MIT de Editor IA — ronda 2026-10-21

Esta nota registra qué repositorios con licencia permisiva se evaluaron para
mejorar el editor, cuáles se integraron, con qué versión y licencia verificada, y
qué quedó fuera con su motivo. La regla del proyecto se mantiene: **nada se
declara integrado si no compila y no tiene pruebas que lo respalden**.

## Política aplicada

- Sólo se integra código con licencia **MIT, Apache-2.0, BSD o Unlicense**.
- Se descarta **GPL/AGPL** dentro del proceso de la app y cualquier licencia
  propietaria o con restricciones de uso comercial automatizado (Remotion sigue
  fuera, como ya documenta el README).
- Cada licencia se consultó en la fuente del ecosistema, no de memoria:
  `npm view <paquete> license` para JavaScript y `crates.io/api/v1/crates/<crate>`
  para Rust. Cuando el metadato no alcanzó, se leyó el archivo `LICENSE` crudo del
  repositorio.
- Una dependencia nueva entra con pruebas propias y con un aviso en
  [`THIRD-PARTY-NOTICES.md`](../../THIRD-PARTY-NOTICES.md).

### Detalle de la integración

**MiniSearch** (`apps/desktop/src/state/global-search.ts`)

- `collectSearchDocuments(project)` es puro: recorre el documento y produce una
  lista plana con `kind`, título, subtítulo, palabras clave y frame.
- `createGlobalSearch` configura `prefix`, `fuzzy: 0.2`, `combineWith: 'OR'` y
  boosts de título; el tokenizador normaliza NFD y quita diacríticos.
- `destinationOfHit` decide vista, selección y playhead; la misma función se usa
  en la app y en las pruebas, así no hay dos criterios distintos.
- El índice se construye **al abrir la paleta** (`paletteOpen`), no en cada
  edición: escribir en la timeline no paga el costo de reindexar.

**fflate** (`apps/desktop/src/state/delivery-package.ts` + `commands/package.rs`)

- El ZIP se arma en el renderer y viaja como base64; Rust valida tamaño (≤64 MB),
  firma `PK\x03\x04`, nombre sin separadores ni `..`, y escribe con temporal +
  `rename` atómico.
- El manifiesto declara conteos, duración, fps, perfiles y hashes; el CSV de
  derechos escapa comas y comillas.
- El LEEME explica en lenguaje llano que los medios no se copian y cómo verificar
  los hashes al mover el proyecto.

**subsrt** (`apps/desktop/src/state/subtitles.ts` + `commands/subtitles.rs`)

- Se importa **`subsrt/lib/format/ssa.js` directo**, no el entry del paquete: ese
  entry carga los nueve formatos con `require('./format/' + nombre + '.js')`, una
  require dinámica que `@rollup/plugin-commonjs` no puede resolver. En el bundle
  de producción lanzaba al evaluar el módulo y dejaba la ventana negra; el
  import directo evita ese camino y mantiene el parser MIT.
- La detección usa `[Script Info]`, `ScriptType: v4.00+` y `[V4+ Styles]` para
  distinguir ASS de SSA; el parser convierte `\N` en salto de línea y quita las
  etiquetas `{...}`.
- El selector nativo ahora acepta `.srt`, `.vtt`, `.ass` y `.ssa` con el mismo
  límite de 4 MB y validación UTF-8.

## Verificación de esta ronda

- `npm run typecheck`: limpio.
- `npm run build` + `vite preview` abierto con Chrome: la interfaz monta sin
  `pageerror`. Esta prueba fue la que aisló el require dinámico de `subsrt` y
  confirmó el arreglo antes de reconstruir el escritorio.
- `npx vitest run --no-file-parallelism`: **718 pruebas en 73 archivos**, 0
  fallos. La variante serial se usó porque el runner paralelo chocó una vez con
  un `EPERM` del entorno al escribir el caché SSR; el mismo conjunto pasa en
  paralelo cuando el sistema de archivos lo permite.
- `npm run test:extension`: 31 pruebas, 0 fallos.
- `npm run test:web-tts`: 10 pruebas, 0 fallos.
- `cargo test -p editor-ia-desktop --offline`: **157 pruebas, 0 fallos, 4
  ignoradas**; incluye 5 del selector de subtítulos (con `.ass`) y 4 del paquete
  de entrega.
- `cargo check -p editor-ia-desktop --offline`: compila tras revertir los
  plugins bloqueados.
