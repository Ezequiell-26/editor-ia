# 03 — Barrido de strings de CapCut 9.7.1 (2026-11-11)

> Objetivo: encontrar la superficie de UI/features real de CapCut 9.7.1 sin
> ejecutarlo, para elegir la próxima mejora de Olyvia con fundamento.
> Instalación: `D:\Users\ofici\_Migrado_de_C\AppData\Local\CapCut\Apps\9.7.1.4203`.

## Método

1. Extracción de strings ASCII + UTF-16LE (≥5 caracteres) de los binarios
   < 64 MB y conteo por vocabulario de features.
2. REA 6.4.0 + Ghidra 12.1.4 (`rea search --kind strings`) para evidencia
   puntual con dirección y `evidence_id`.
3. Cruce con AlaukCut (`frontend/js/`) cuando CapCut no expone la cadena.

## Evidencia REA

- `rea search FusionUI.dll "Marker"` → **39 strings**, ev
  `ev_8b6529c12f7d88b3531d3ecda1a255178bc6447884635cc59e506ab4af2f43f8`.
  Todas son de `QUITreeView` (`markerShowed`, `markerWidth`,
  `indentationMarkerFollowsCell`). **No hay marcadores de timeline en ese
  DLL**: la UI real de CapCut vive en QML compilado, no en `FusionUI.dll`.
- `rea search EffectPlatform.dll "keyframe"` → colgado >5 min, sin resultado;
  descartado (no se usa como evidencia).
- `rea search res_pool.dll "favorite"` → ver §Resultado pendiente.

## Aprendizaje aplicable a Olyvia

1. **Favoritos de efectos/transiciones** (CapCut `EffectPlatform` +
   `res_pool`): `favorite_count`, `has_favorited`, `_fav_scene`, tablas SQL de
   favoritos y búsqueda. Olyvia tiene búsqueda en el rail de medios, pero **no
   un sistema de favoritos para efectos/transiciones**. Candidato claro de
   próximo ciclo (frontend + persistencia local).
2. **Audio**: CapCut 9.7.1 trae `denoise`, `loudness`, `tts`, `beat`,
   `tracking` en `audioeffect.dll`. Olyvia ya cubre denoise, loudness, beat y
   parte de tracking; TTS existe por SAPI/ElevenLabs. Sin gap inmediato.
3. **Beauty / body / avatar**: aparecen en el pool (`beauty` 9, `body` 8,
   `avatar` 17) pero dependen de modelos on-device; fuera de alcance inmediato.
4. **Marcadores**: CapCut no expone strings de timeline en `FusionUI.dll`; el
   grounding útil es **AlaukCut** (`frontend/js/marcadores.js`):
   - `proximo: () => irPara_(1)` / `anterior: () => irPara_(-1)`.
   - Marcadores `.marcador-regua` sobre la regla, arrastrables, con estado
     `selecionado` y borrado con la tecla de eliminar.
   - Sin colores por marcador en AlaukCut; Olyvia ya tiene 8 colores y panel.

## Resultado del REA sobre `res_pool.dll`

`rea search res_pool.dll "favorite"` **falló con `provider_timeout`** a los
330 s (`timeout_ms: 330000`, operación `search_strings`). El binario de 8,8 MB
supera el presupuesto por defecto de Ghidra en este entorno. Para una próxima
pasada: subir `REA_GHIDRA_STARTUP_TIMEOUT_MS` o elegir un binario menor
(`EffectPlatform.dll` de 1,5 MB también colgó en el intento anterior). El
vocabulario de strings ya confirma la existencia de favoritos y búsqueda en el
pool, pero **no se usa como evidencia de comportamiento**.

## Límite

El barrido de strings prueba **vocabulario y nombres de tablas/API**, no
comportamiento. Ninguna conclusión de UX se apoya sólo en esto.
