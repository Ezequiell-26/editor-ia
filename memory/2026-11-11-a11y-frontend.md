# 2026-11-11 (noche 3) — Accesibilidad del front + benchmark de cloneProject

## Performance (MCP hotspot)
- `cloneProject` (fan-in 106) usa `JSON.parse(JSON.stringify(...))`.
- Benchmark con proyecto sintético realista (assets, clips, transform/effects/
  audio keyframes):
  - 40 clips: JSON 1,3 ms · structuredClone 1,6 ms
  - 120 clips: JSON 2,1 ms · structuredClone 3,7 ms
  - 300 clips: JSON 4,5 ms · structuredClone 6,8 ms
- **No se cambia**: el clon actual es más rápido para esta forma de datos.
  Medir antes de optimizar evitó una regresión del ~50 %.

## Auditoría a11y (Playwright, arnés temporal)
- 18 vistas (`editor`, `home`, `projects`, `assets`, `visuals`, `settings`,
  `lab`, `learn`, `script`, `production`, `download`, `creator`, `mcp`,
  `director`, `mixer`, `vfx`, `text-edit`, `motion`) + 3 estados del editor
  (base con clip, export, paleta de comandos, atajos).
- Chequeos: nombre accesible de botones/roles, labels de inputs, `img alt`,
  ids duplicados, `tabindex > 0`, `aria-hidden` con enfocables.
- **Antes**: 3 buscadores sólo con placeholder + 2 inputs del Inspector sin
  `aria-label`.
- **Corregido**:
  - `features/assets/AssetsPanel.tsx`: `aria-label` + `title` al buscador.
  - `components/ThumbnailBrowser.tsx`: `aria-label={searchPlaceholder}`.
  - `components/CommandPalette.tsx`: `aria-label` al buscador.
  - `features/editor/Inspector.tsx`: `aria-label` a los inputs de subtítulo y
    título del playhead.
  - Tests: `CommandPalette.focus.test.tsx` y `AssetsPanel.test.tsx` afirman el
    nombre accesible (un placeholder NO es nombre accesible).
- **Después**: 0 en todos los chequeos. Único residuo: 31 `.num-spin` con
  `tabindex="-1"` dentro de `aria-hidden`; no están en el orden de tabulación y
  el input tiene nombre propio → aceptable, documentado.

## Gotchas
- `AssetsPanel` con biblioteca vacía muestra empty-state **sin buscador**; el
  test de a11y necesita al menos un asset (`renderPanel([image('foto.png')])`).
- `type="search"` se consulta con `getByRole('searchbox')`; `type="text"` con
  `getByRole('textbox')`.
- El arnés con `createDemoProject` sirve para auditar render (no mutar): sus IDs
  no son UUID y `parseProject` rechaza ediciones.
